## 三、變更明細
### 配置/基礎設施（VPS 172.236.143.108）
- **Nginx** `/etc/nginx/conf.d/beaver.conf`：從單一 `server_name _` 改為 6 個域名獨立 server block
  - `8811.info` / `www.8811.info` → 下載頁（`/var/www/download`）
  - `download.8811.info` → 鏡像文件下載（autoindex 開啟，大文件傳輸優化）
  - `api.8811.info` → API 網關（:20800）+ WebSocket（:20400）
  - `oauth.8811.info` → OAuth 授權服務（open_portal :22000）
  - `admin.8811.info` → 管理後台（beaver-manager :8080）
- **SSL 證書**：Let's Encrypt 簽發，覆蓋全部 6 個域名，有效期至 2027-01-16，已配置自動續期
- **Certbot**：安裝 `certbot` + `python3-certbot-nginx`（EPEL 源，Rocky Linux 9.8）
- **HTTP → HTTPS 重定向**：Certbot `--redirect` 自動配置

## 六、注意事項與後續
1. **oauth.8811.info 返回 404**：open_portal（:22000）根路徑無對應頁面，需確認 beaver-oauth H5 前端是否已部署到該服務的指定路由下（如 `/oauth/authorize`）
2. **鏡像文件管理**：`download.8811.info` 的 `/var/www/download/` 目前僅有 `index.html` 和 `latest.apk`，後續版本更新需同步上傳安裝包
3. **回滾方式**：`certbot revoke` + 恢復 `beaver.conf` 備份 + `nginx -s reload`
4. **域名 DNS**：6 個域名均指向 172.236.143.108，5 條 A 記錄（www 為 CNAME 或同 A 記錄）
5. **內部服務架構**（192.168.0.104 → 172.236.143.108 via Tailscale）：
